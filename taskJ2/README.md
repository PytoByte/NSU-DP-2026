### Параметры

| параметр             | описание                    | по умолчанию |
|----------------------|-----------------------------|--------------|
| --type=linked\|array | реализация списка           | linked       |
| --threads=N          | число дочерних нитей        | 3            |
| --between=MS         | задержка между шагами       | 1000         |
| --inside=MS          | задержка внутри шага        | 0            |
| --maxLine=N          | порог резки строки          | 80           |
| --benchmark=N        | замер на N записях          | 0            |
| --duration=MS        | ограничить замер окном в MS | 0            |

### Суммарное число шагов за время $T$

$N$ — число нитей, $T$ — время работы, $t_{\text{inside}}$ — задержка внутри шага,
$t_{\text{between}}$ — задержка между шагами.

- $S_{\text{теор linked}} = N \cdot \frac{T}{t_{\text{inside}}+t_{\text{between}}}$ — верхняя оценка. Шаг держит три соседних
  узла, поэтому при $N>1$ тройки соседних нитей перекрываются и реальное число шагов ниже.
- $S_{\text{теор array}} = \min (\frac{T}{t_{\text{inside}}}, N \cdot \frac{T}{t_{\text{inside}}+t_{\text{between}}})$. Задержка $t_{\text{inside}}$ проходит под общим
  локом на весь список, поэтому все нити вместе делают не больше $\frac{T}{t_{\text{inside}}}$ шагов.
  Одна нить ограничена своим циклом $t_{\text{inside}}+t_{\text{between}}$, отсюда $\min$.

### Замеры

$T = 30 000$ мс, $t_{\text{inside}} = t_{\text{between}} = 300$ мс, $n = 50$.

Параметры: `--type=linked|array --threads=N --benchmark=50 --duration=30000
--between=300 --inside=300`
