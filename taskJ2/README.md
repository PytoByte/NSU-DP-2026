## Запуск

Свой linked list
```powershell
./gradlew run --args="--type=linked --threads=3 --between=1000 --inside=10"
```

Synchronized array list
```powershell
./gradlew run --args="--type=array  --threads=3 --between=1000 --inside=10"
```

замер 50 записей, стоп после полной сортировки
```powershell
./gradlew run --args="--type=linked --threads=3 --benchmark=50"
```

замер длительностью 2сек с задержкой 1мс между шагами
```powershell
./gradlew run --args="--type=array --threads=4 --benchmark=50 --duration=2000 --between=1"
```

| аргумент | смысл | по умолчанию |
|---|---|---|
| `--type=linked\|array` | реализация списка | `linked` |
| `--threads=N` | число дочерних нитей | `3` |
| `--between=MS` | задержка между шагами | `1000` |
| `--inside=MS` | задержка внутри шага | `0` |
| `--max-line=N` (`--maxLine`) | порог резки строки | `80` |
| `--benchmark=N` | headless-замер на N записях | — |
| `--duration=MS` | окно замера (иначе — до полной сортировки) | — |

Пустая строка печатает текущий список; `Ctrl+D` / `Ctrl+Z` завершает работу и
печатает суммарное число шагов (`Sort steps count: N`).

## Теоретический расчёт

`n` — число записей, `k` — число нитей, `D` — окно замера,
`Δ` — время одного шага (задержка `inside + between` плюс накладные расходы).
Шаг — одно сравнение пары соседей.

1. **Один поток.** За проход `n-1` сравнений, проходов до порядка `P ≤ n-1`:

   `steps(1) = P·(n-1) ≤ (n-1)²`.

2. **`k` потоков.** Нити дублируют одни и те же проходы, поэтому список
   упорядочивается примерно в `k` раз быстрее, и суммарные шаги растут слабо:

   `steps(k) ≈ P·(n-1) + O(повторы при конкуренции)`.

3. **Задержки.** Если шаг упирается в `sleep`, за окно `D` каждая нить делает
   ≈ `D/Δ` шагов:

   `steps(k, D) ≈ k·D/Δ`.

## Статистика

`--benchmark=50`, данные детерминированы (seed 42), `n = 50`, медианы 3 прогонов.

| нитей | до сортировки: `linked` | до сортировки: `array` | окно 2 с / 1 мс: `linked` | окно 2 с / 1 мс: `array` |
|---:|---:|---:|---:|---:|
| 1 | 2254 | 2254 | 1193 | 1254 |
| 2 | 2303 | 2303 | 2419 | 2471 |
| 3 | 2352 | 2450 | 3504 | 3618 |
| 4 | 2401 | 2450 | 4766 | 4848 |

`2254 = 46·49 = P·(n-1)` — один поток, обе реализации (алгоритм один и тот же).
С ростом `k` суммарные шаги растут слабо (нити дублируют проходы); с задержками
число шагов линейно растёт по `k` (≈ 1200 шагов на нить за 2 с).
